2. Qué información utiliza RutaCoste

RutaCoste no requiere que el usuario cree una cuenta ni introduzca una contraseña para utilizar la calculadora.

Cuando utilizas la calculadora, puedes introducir información como una ubicación de origen, una ubicación de destino, el consumo del vehículo y el precio del combustible.

Las ubicaciones introducidas pueden enviarse a servicios externos de geocodificación y cálculo de rutas necesarios para obtener la distancia y/o ruta solicitada.

3. Servicios externos de rutas

Para determinadas funciones de cálculo de rutas, RutaCoste puede utilizar servicios de terceros como OpenStreetMap, Nominatim y OSRM.

Estos servicios pueden recibir la información necesaria para procesar una solicitud de búsqueda de ubicación o cálculo de ruta. El tratamiento que realicen estos terceros estará sujeto también a sus propias políticas y condiciones.

4. Almacenamiento local

RutaCoste utiliza almacenamiento local del navegador (localStorage) para recordar la elección realizada por el usuario respecto al aviso de cookies.

Actualmente se utiliza el identificador rutacoste-cookies para recordar si el usuario ha aceptado o rechazado dicho aviso.

Esta información se almacena localmente en el navegador del usuario y no constituye un registro de rutas realizadas en un servidor de RutaCoste.

5. Google Tag Manager

RutaCoste utiliza Google Tag Manager para gestionar determinados elementos técnicos y etiquetas del sitio web.

Google Tag Manager puede facilitar la carga de otras etiquetas o servicios configurados en el contenedor correspondiente. El tratamiento de datos que realicen dichos servicios dependerá de las etiquetas que se encuentren activas.

En el momento de esta actualización, RutaCoste no utiliza directamente Google Analytics mediante una etiqueta gtag en el código revisado del sitio.

6. Publicidad y Google AdSense

En el momento de esta actualización, RutaCoste no tiene implementado Google AdSense en sus páginas.

Si en el futuro se incorpora Google AdSense, esta política se actualizará antes o junto con dicha implementación para informar sobre los proveedores, tecnologías de publicidad y tratamientos correspondientes.

Google establece requisitos específicos de consentimiento para usuarios del Espacio Económico Europeo, Reino Unido y Suiza cuando se utilizan sus productos publicitarios. En particular, para anuncios personalizados Google exige el uso de una plataforma de gestión del consentimiento (CMP) certificada e integrada con el marco TCF de IAB. Más información sobre los requisitos de Google .

7. Base jurídica

Cuando exista un tratamiento que requiera consentimiento, este se solicitará mediante el mecanismo de consentimiento correspondiente antes de activar las tecnologías que dependan de dicho consentimiento.

Los tratamientos estrictamente necesarios para prestar las funciones solicitadas por el usuario podrán realizarse cuando exista una base jurídica que lo permita.

8. Conservación de la información

RutaCoste no mantiene actualmente un historial de las rutas calculadas por los usuarios en una base de datos propia.

Los terceros utilizados para determinadas funciones podrán aplicar sus propios períodos de conservación de acuerdo con sus políticas.
