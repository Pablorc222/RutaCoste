2. Qué información utiliza RutaCoste

RutaCoste no requiere que el usuario cree una cuenta ni introduzca una contraseña para utilizar la calculadora.

Cuando utilizas la calculadora, puedes introducir información como una ubicación de origen, una ubicación de destino, el consumo del vehículo y el precio del combustible.

Las ubicaciones introducidas pueden enviarse a servicios externos de geocodificación y cálculo de rutas necesarios para obtener la distancia y/o ruta solicitada.

3. Servicios externos de rutas

Para determinadas funciones de cálculo de rutas, RutaCoste puede utilizar servicios de terceros como OpenStreetMap, Nominatim y OSRM.

Estos servicios pueden recibir la información necesaria para procesar una solicitud de búsqueda de ubicación o cálculo de ruta. El tratamiento que realicen estos terceros estará sujeto también a sus propias políticas y condiciones.

4. Almacenamiento local

RutaCoste utiliza almacenamiento local del navegador (localStorage) para recordar la elección realizada por el usuario respecto al aviso de cookies.

Actualmente se utiliza el identificador rutacoste-cookies para recordar si el usuario ha aceptado o rechazado dicho aviso.

Esta información se almacena localmente en el navegador del usuario y no constituye un registro de rutas realizadas en un servidor de RutaCoste.

5. Google Tag Manager y Google Analytics

RutaCoste utiliza Google Tag Manager para gestionar las etiquetas y servicios técnicos del sitio web, incluida la etiqueta de Google AdSense descrita en el punto siguiente.

Google Tag Manager puede facilitar la carga de otras etiquetas o servicios configurados en el contenedor correspondiente, como Google Analytics. El tratamiento de datos que realicen dichos servicios dependerá de las etiquetas que se encuentren activas en cada momento y del consentimiento que el usuario haya otorgado.

6. Publicidad y Google AdSense

RutaCoste utiliza Google AdSense para mostrar publicidad en sus páginas. Google, como proveedor externo, puede utilizar cookies y tecnologías similares para mostrar anuncios basados en visitas anteriores del usuario a este sitio web u otros sitios de Internet.

RutaCoste ha implementado Google Consent Mode: por defecto, el almacenamiento relacionado con publicidad y analítica se establece como denegado hasta que el usuario responde al aviso de cookies. Si el usuario acepta, ese consentimiento se comunica a Google para permitir, en su caso, anuncios personalizados; si lo rechaza, los anuncios que puedan mostrarse se sirven sin personalización basada en dicho consentimiento.

Google establece requisitos específicos de consentimiento para usuarios del Espacio Económico Europeo, Reino Unido y Suiza cuando se utilizan sus productos publicitarios. En particular, para anuncios personalizados Google exige el uso de una plataforma de gestión del consentimiento (CMP) certificada e integrada con el marco TCF de IAB; el aviso de cookies de RutaCoste, combinado con Google Consent Mode, cubre el requisito mínimo de consentimiento, si bien no se trata de una CMP certificada por el IAB.
